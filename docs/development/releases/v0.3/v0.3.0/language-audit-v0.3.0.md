# v0.3.0 语言与用户文档审计

依据 design-v0.3.0 的语言规范。此清单记录源码与 Markdown 审阅；上线导航/页面检查仍属于远端验收，不由本清单代替。

| 范围 | 检查与处理 | 结论 |
| --- | --- | --- |
| README、站点首页 | 列出全部六个 API；日历说明覆盖五个日频 API | 已修正旧版两接口说明 |
| guide/ | 配置、快速开始、下载及 Excel 示例英文；下载说明补齐五接口 update/filter 和 suspend_d 空/冲突语义 | 已审阅 |
| reference/ | CLI 列表与 API 字段页列全六个接口，日期、键、NULL 和 stale 规则一致 | 已审阅 |
| operations/ | 数据库、读权限、备份恢复、维护和显式清理教程英文 | 已审阅；功能/环境实证另行签核 |
| development 教程 | setup/testing/benchmarks/documentation 及导航英文，历史验收分析中文保留 | 已转换 |
| src/、.env.example、.github/、scripts/ | 自有代码/注释/配置与提示无中文；新事件说明英文 | 文本扫描与人工检查通过 |
| benchmarks/、测试说明 | benchmark 提示和生成摘要英文；集成测试 README 英文 | 已转换，实际生成结果已检查 |
| 中文测试内容 | reporting/progress 测试保留中文输入，以覆盖 Unicode；它们不是产品默认文案 | 合理例外 |
| 原始数据、设计、历史证据 | 不翻译原始值；定稿设计与既有验收记录保持原样 | 保持原文 |
| Demo | 中文设计控制说明、英文模拟终端；旧设计演示有版本边界，不作为真实终端验收 | 保留并核对构建嵌入 |

产品文档仍链接上一版已发布验收记录，不能把当前进行中的 v0.3.0 验收称作已发布。发布完成时更新链接。

## BL-009 · 扩展面向量化研究的数据集合 {#bl-009}

- 分类：数据集扩展
- 状态：待规划
- 目标版本：未定
- 关联设计／证据：待设计

- [ ] 扩展支持的 Tushare 数据集合，使其基本满足量化研究的数据需求。
  - 状态：v0.3.0 的 A 股日频阶段已完成并验收，新增 daily、adj_factor、stk_limit、suspend_d；整体扩展事项保持开放，ETF、财务及指数等后续评估。
  - 先定义“基本支持”的研究场景与市场范围，再确定最小可用数据集合和分阶段优先级。
  - 候选类别包括证券基础信息与历史状态、交易日历、行情与复权因子、停复牌与涨跌停信息、指数行情与历史成分/权重、财务报表及指标；具体 API 待调研确认。
  - 逐个评估权限/积分、历史可得范围、请求限制、唯一键、数据变更类型及 fetch/refresh/update 策略。
  - 关注公告日、报告期、修订版本、退市证券和历史成分等研究所需原始信息，说明前视偏差与幸存者偏差相关的可得性限制。
  - 保持下载器职责：获取和存储原始数据；清洗、因子计算、关系构建及回测仍由后续研究环节负责。

### 验收条件

1. 提供“研究场景—所需数据—对应 API—权限与限制”的覆盖矩阵，明确已支持及缺口。
2. 选定的最小数据集合可完成一个代表性的量化研究数据准备流程，并列出尚需外部补充的数据。
3. 每个新增 API 有明确字段、键、请求规划、更新与核对规则，并通过对应协议和独立数据库测试。
4. 不将请求成功或接口数量作为研究数据完整性、历史时点可用性的证明。

已完成阶段单列为 [BL-015](index.md#bl-015)；本项仅管理超出 v0.3.0 A 股日频范围的后续扩展，原研究目标及验收原则保留。
